# Teachingpowers

Compatibility entry point for `using-teaching`. Read and follow that skill, preserving the user's request, destinations, restrictions, active plan and confirmed inputs. Do not start a second planning or publication workflow.

Before delegation, read the repository-root `POWERS.md` when it exists and
apply only its `teachingpowers` section. Use `new-powers-policy` for an
explicitly local `POWERS.md` amendment or a global teachingpowers default;
never infer one scope from the other.
