# Notes style

| Field | Value |
| --- | --- |
| Status | Adopted |
| Approved by | Fixture project owner, as initial scenario state |

Document kind: notes. Audience and terseness: the current request supplies them;
otherwise use readers familiar with integer arithmetic and ordinary prose.

State hypotheses explicitly. Define notation before its first use in the final
exposition. Propositions, definitions, examples, remarks and conjectures are
available; do not add lemmas or corollaries. Include complete elementary proofs
relative to the audience; finite checks do not establish universal statements.
Unsupported desired results remain questions or conjectures. Number and explain
relevant counterexamples, including the expectation they correct.

Keep source lines at most 80 characters. Wrap agent-authored changes in
% >>> [agent-<harness> <date> <slug>] and matching % <<< tags. Comment out
superseded text rather than deleting it. Never edit or delete human comments,
tags, \taylor{} or \todo{}; adjacent \agentreply{} is the response channel.
Agent claim states and review metadata belong in Markdown, not the TeX.
An opening topic explanation is welcome; no finished-paper abstract is requested.
