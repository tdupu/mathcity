# Square bounds

Version: R2. Original R1 remains at ai/prior/bounds-v1.md.

## B1: desired strengthened target

For every real number x, x squared<=x. The interval hypothesis has been removed
from the desired target. The old derivation starts with x(1-x)>=0; that step
has not been justified for arbitrary real x.

## B2: boundary of the old argument

x=2 gives x squared=4>2, and x=-1 gives x squared=1>-1. These values contradict
the strengthened target. The argument and equality discussion in R1 still
apply to 0<=x<=1; the old proof did not cover the new scope.

## B3: equality equation

For all real x, the equation x squared=x is equivalent to x(x-1)=0, so its
solutions remain 0 and 1. This equation does not imply an inequality for all x.
