# Adjudicated-Brief Rejection Guard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the brief gate discarding verdicts a human has already given, and recover the ones it discarded.

**Architecture:** `brief-shuffle` re-gates any item it finds in `.staging/` and rejects failures into `.pile/.rejected/`. It has no notion of "this was already decided", so a brief that re-enters staging after adjudication is re-judged by a machine and can be thrown away. The fix is a precedence rule — **an adjudicated brief is terminal; the gate must refuse to re-judge it** — enforced in the one place that decides promote-vs-reject, plus a recovery pass for items already in `.rejected/`.

**Tech Stack:** Python 3 (`mctl_core`), pytest, Gas City formula TOML, bash smoke tests.

**Spec:** bead `mc-8ehd0` (P0, open) — *"brief gate moves ALREADY-ADJUDICATED briefs to .rejected/ — 7 of Taylor's approve verdicts bounced"*. Supporting measurements in `mc-glpm0` (2026-08-28 `/doubt` comment).

## Global Constraints

- **Do NOT weaken the gate.** Rejection is correct for briefs that genuinely fail a gate. The defect is re-judging a decided brief, not rejecting an undecided one.
- **`.pile/.rejected/` is durable evidence.** Recovery moves copies forward; it does not delete rejection records (`formulas/brief-producer-failure-record.toml` reads them).
- **mctl is the sole authorized writer of governed brief artifacts** (POLICY B2.11). `brief-shuffle.toml` already violates this (bead `mc-2qqo`, open). Do not add new direct writes; route new state through `mctl_core`.
- **P6.2 — a check must be able to fail.** Every test below states the observed failing case it was written against.
- **P1.19 — append, don't edit** adjudicated beads.
- Commit footer: `[autogenerated by Claude <model> v<version> on <datetime>]`. Never `Co-Authored-By: Claude` (P5.5).

```python
def is_adjudicated(frontmatter: Mapping[str, Any]) -> bool:
    """Whether a human has already decided this brief.

    True means the gate MUST NOT re-judge it. A machine re-running its gates
    over a decided brief and rejecting it discards a human's verdict, which is
    what mc-8ehd0 records.

    An empty `verdict:` is an ABSENT verdict, not a decision -- the same
    distinction `unknown` vs `zero` carries everywhere else in this codebase.
    """
    verdict = str(frontmatter.get("verdict") or "").strip()
    if verdict:
        return True
    return str(frontmatter.get("status") or "").strip().lower().startswith("adjudicated")
```

```python
def regate_diagnostics(frontmatter: Mapping[str, Any]) -> tuple[Diagnostic, ...]:
    """Refuse to re-judge a brief a human already decided (mc-8ehd0).

    ERROR rather than WARN on purpose: the downstream consequence is a verdict
    moved to `.pile/.rejected/`, and a warning that a caller may ignore is not
    a guard. The gate's correct move on seeing this is to leave the item where
    it is and escalate, never to reject it.
    """
    from .verdicts import is_adjudicated

    if not is_adjudicated(frontmatter):
        return ()
    return (
        _diagnostic(
            None,
            Severity.ERROR,
            "MBRF_ADJUDICATED_REGATE",
            "This brief already carries a verdict; the gate must not re-judge it.",
            policy_ref="B2.2",
        ),
    )
```

```python
# assets/scripts/mctl_core/rejected_recovery.py
"""Find human verdicts sitting in `.pile/.rejected/` (mc-8ehd0).

READ-ONLY. This module reports; it moves nothing. Recovery is a human
decision per brief, because a verdict recorded against a brief that has since
changed may no longer apply, and re-promoting it silently would assert a
judgement nobody made about the current text.
"""
from __future__ import annotations

from pathlib import Path
from typing import Any, Mapping

from .fields import read_frontmatter
from .verdicts import is_adjudicated


def scan(rejected_root: Path) -> tuple[Mapping[str, Any], ...]:
    """Every rejected brief that carries a verdict, worst case first."""
    if not rejected_root.is_dir():
        return ()
    found: list[Mapping[str, Any]] = []
    for path in sorted(rejected_root.rglob("*.md")):
        try:
            front = read_frontmatter(path.read_text(encoding="utf-8", errors="replace"))
        except OSError:
            continue
        if not is_adjudicated(front):
            continue
        found.append(
            {
                "slug": str(front.get("slug") or path.parent.name),
                "path": str(path),
                "verdict": str(front.get("verdict") or "").strip(),
                "adjudicated_by": str(front.get("adjudicated_by") or "").strip(),
            }
        )
    return tuple(found)
```

## §E Wheel-check / check-zero (P1.20)

Task 4 modifies a formula, so P1.20 requires a documented survey before
dispatch. Four places the guard could live were considered:

| Alternative | Verdict | Why |
|---|---|---|
| **Guard inside `brief-shuffle.toml` only** (prose rule in the formula) | **ADAPT — partially adopted** | It is where the promote/reject decision is made, so the rule must appear here. But a formula is prose executed by an agent; it cannot be unit-tested, and a rule that exists only as prose has no failing case. Adopted as the *enforcement point*, not as the whole fix. |
| **Guard in `mctl_core` as a typed diagnostic** | **ADOPT** | Testable, has an observed failing case, and reusable by any other caller that gates a brief. Tasks 2-3. This is why the fix is split across a predicate, a diagnostic, and a formula rule rather than being one formula edit. |
| **Guard at brief INTAKE — refuse to stage an adjudicated brief at all** | **RULE OUT (for now)** | Arguably the true root cause: a decided brief should never reach `.staging/`. Ruled out because the re-entry path is not yet established — Task 1 Step 4 measures it. Fixing intake before knowing how items re-enter would be a workaround at the wrong layer (P1.17). **Revisit once Task 1 names the mechanism; if intake is the source, file a follow-up bead rather than widening this plan.** |
| **Make `.pile/.rejected/` non-destructive instead** (never move, only tag) | **RULE OUT** | Changes the meaning of an existing durable artifact that three other consumers read (`brief-producer-failure-record.toml`, `brief-archive-sweep.toml`, `brief-check.sh:341`). Larger blast radius than the defect, and it would leave the gate still *judging* decided briefs — treating the symptom, not the precedence error. |

owned set — `mctl_core/`, `formulas/`, `tests/mctl/`, `docs/`. No gascity core,
