# Typed bead-write verbs (mc-p0wps) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add three typed bead-write verbs — `bead_close`, `bead_hold`, `bead_release` — to the mctl MCP surface, filling the P7.3 interface gap that mc-i9bwz option A adjudicated.

**Architecture:** Follow the four-part write-tool pattern (input dataclass → pure `plan_*` builder with refusals as preconditions → thin `_handle_*` → `ToolSpec`). Close mirrors `plan_molecule_cancel` (effects.py:1214) but closes ONE bead. Hold/release set/clear a `hold:*` label via a new `apply_bead_label` effect path.

**Tech Stack:** Python 3.11, mctl_core, `bd` CLI (subprocess), pytest.

## Global Constraints (verbatim from spec + POLICY.md)

- Every mutation: `dry_run` default **true**; refusals visible in dry-run (emit as blocking `Diagnostic` preconditions or raise `MutationError` — both flow through the shared `_raise_if_blocked`).
- `force` is **deps-only**: it downgrades ONLY the blocked-by-deps refusal. It does **NOT** bypass `MBCL_ROOT_HAS_OPEN_STEPS` (adjudicated 2026-08-28).
- `if_status=observed.status` on every close → inherits `MCTL_BEAD_UPDATE_RACE_LOST` (exit 13).
- Labels: colon-form or bare only; reject slashes (MBRF033).
- P6.2: every refusal ships an observed failing-then-passing test; mutation-prove the root guard.
- P5.5: no `Co-Authored-By`; use `[autogenerated by Claude Opus 4.8 v2.1.231 on <ts>]` footer.
